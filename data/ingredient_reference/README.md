# Curated Ingredient Reference Data

This directory will hold curated, cited, versioned source data for ingredient definitions, regulatory limits, and nutritional attributes.

## Principles:
1. **Credible Sources Only:** All definitions and thresholds must cite official regulatory or scientific bodies (e.g., FSSAI, ICMR, WHO, Codex Alimentarius).
2. **Provenance & Versioning:** Every dataset must include its retrieval date, publication version, and license notes.
3. **No Hallucinated Effects:** Never invent health attributes or make unverified health claims.
4. **Deterministic Lookup:** Data here is used for deterministic string-matching and explanation lookups, not probabilistic guessing.
